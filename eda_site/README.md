# EDA Website (Track A)

Bu papka majburiy EDA veb-saytining manba kodini saqlaydi. Texnologiya erkin — Streamlit, statik HTML, yoki boshqa framework.

Sayt quyidagi 7 bo'limni albatta qamrab olishi kerak (TASKS.md → Track A):

1. Yondashuvning qisqacha tavsifi
2. Dataset umumiy ko'rinishi va tuzilishi
3. Bir nechta mazmunli EDA vizuallari
4. Tranzaksiya tarixidan asosiy kuzatuvlar
5. Target taqsimoti va xulq-atvor patternlari tahlili
6. EDA'dan kelib chiqqan feature/model g'oyalari
7. Qisqa xulosa

## Tezkor boshlash (Streamlit variant)

```bash
pip install streamlit
streamlit run eda_site/app.py
```

`app.py` faylini shu papkaga yarating (hali mavjud emas — Track A vazifasi).
Statik HTML/GitHub Pages variant tanlansa, `index.html` shu yerga qo'yiladi.
